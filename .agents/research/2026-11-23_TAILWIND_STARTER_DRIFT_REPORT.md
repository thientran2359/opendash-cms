## tailwind-frontend-and-starter-theme-v3.md

- **P2 — CTA URL option is inert.** At merged source `091310c2e0d6e74b56be72221a928c3e5b6a0049`, `cms/crates/opendash-server/src/builtin_themes/opendash-starter/theme.json` exposes public string option `header_cta_url`, but `header.html:1` hardcodes `/gioi-thieu`. C-SEC correctly excludes untyped `options.*` from URL interpolation; implementing configurable href requires an approved typed URL delta covering schema, validation, context, preview, Admin and immutable revision upgrades. Follow-up: [#495](https://github.com/thientran2359/opendash-cms/issues/495).
- **P2 — Post-specific template bypasses archive authority.** `cms/crates/opendash-server/src/builtin_themes/opendash-starter/single-post.html:1` hardcodes its back link to `/posts`, whereas the spec requires the standard `archive_url` context and `routes/public_content.rs` supplies it. Configured Posts Page/archive routes cannot control this link. Use the authoritative URL with an absent-archive guard through the approved conformance delta (#495).
- **P2 — Banner richtext lacks the specified typography protection.** `cms/crates/opendash-server/src/builtin_blocks/banner/render.html:4` inserts richtext `body` into `.od-banner-body` without `.od-prose`. The nonce renderer inserts sanitized markup without a typography wrapper; outside another prose container, Tailwind Preflight resets headings, list markers and paragraph margins. Card/Accordion apply `.od-prose`; Banner does not. Include richtext heading/list/paragraph coverage in #495.
