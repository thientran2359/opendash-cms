- **Windows pre-0009 optional rollback:** trong `windows_auth_smoke.py` trên Windows #109, ca `--baseline-binary` pre-0009 được ghi nhận **SKIP** (không có executable pre-0009 Windows riêng); ca rollback bắt buộc M3 v0011 → M4 v0014 → M3 v0011 đã **PASS**.

- **Phạm vi chưa chạy (`NOT_RUN`):** Apple Silicon (arm64), Linux VPS (thuộc M8), và production deployment.
- **Tình trạng M5:** Tài liệu bàn giao này **không** tự phê duyệt G2/G3 hoặc cấp `Ready` cho M5; M5 tuân thủ [ADR-0012](../decisions/ADR-0012-m5-theme-templates.md) và [M5_THEME_TEMPLATES.md](../contracts/M5_THEME_TEMPLATES.md).
