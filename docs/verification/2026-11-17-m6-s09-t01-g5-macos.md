## Test-only delta, negative cases và giới hạn

Test hiện mô phỏng từng HTTP invocation với một `Instant::now()+10s` **mới**, thay vì dùng chung deadline bị hao khi full suite tải nặng. **Production egress không đổi**, HTTP request timeout thực sự vẫn capped **2s**, không nâng quota hoặc bỏ bypass checks. Mock server có read/write timeout, RAII dừng và join thread; biến `HTTP_PROXY` của fixture được override trước khi spawn thread và tự restore sau khi server dừng.

Giữ nguyên matrix `is_forbidden_ip` (private IPv4, link-local, mapped IPv6, ULA, NAT64), mixed DNS reject, method/path/header/CRLF/credential policy, redaction, bounded-reader 1 MiB và HTTP oversized rejection. Bổ sung redirect local observable destination: response **302**, `redirect_destination_hits == 0` cả link-local và redirect local; oversized mock request counter **1** và response **Err**. Một diagnostic thử ép exact network quota error string bị fail vì HTTP client có thể trả `Lỗi khi đọc response HTTP.`; giữ **assertion gốc** rằng oversized network response phải fail closed, đồng thời unit `read_bounded_chunks` chứng minh giới hạn 1 MiB chính xác. Không tuyên bố mọi network error đều do quota.

**Historical Windows F09:** [Windows Beta audit ngày 2026-11-16](2026-11-16-usable-beta-windows-audit.md) đã ghi native Windows full release suite **FAIL exit 101** với redirect `Lỗi kết nối HTTP: Không thể hoàn thành yêu cầu`, trong khi isolated target PASS. Mac baseline đã PASS nên không chứng minh nguyên nhân chính xác của Windows FAIL. Windows **native revalidation trước common RC** vẫn bắt buộc; không sửa audit lịch sử thành PASS. Các phần **NOT_RUN** ở task này: native Windows/Linux parity, B01–B10 full browser Beta, human dogfood, production egress, V1 release authorization.
