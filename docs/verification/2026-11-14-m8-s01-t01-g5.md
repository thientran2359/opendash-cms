## Scope Implemented

1. **Migration [`0032_operations_jobs.sql`](../../cms/migrations/0032_operations_jobs.sql):**
   - `operation_jobs` (`id` 64-char hex `CHECK`, `kind`, `state`, CAS `version`, `actor_user_id`, `reason`, `summary_json`, `error_code`, `error_message`, timestamps).
   - Partial unique index `idx_operation_jobs_single_active_heavy` enforcing max 1 active heavy job (`backup|restore|reconcile|purge` in `queued|running`) per site.
   - `maintenance_generation` singleton table (`id = 1`, `generation`, `last_kind`, `updated_at`).
2. **Canonical Path & Symlink/Reparse Guard ([`paths.rs`](../../cms/crates/opendash-server/src/paths.rs)):**
   - `SitePaths::canonicalize_for_runtime()` resolves relative overrides against `cwd`, rejects symlinks/Windows reparse points on roots and existing ancestors, creates runtime/db parent dirs, canonicalizes `site_root` and `db_path` parent, and exposes `ordered_lock_paths()`.
3. **Site Coordinator & Admission Gate ([`operations.rs`](../../cms/crates/opendash-server/src/operations.rs), [`main.rs`](../../cms/crates/opendash-server/src/main.rs), [`app.rs`](../../cms/crates/opendash-server/src/app.rs)):**
   - `SiteCoordinator::acquire(SitePaths)` acquires exclusive OS locks via `std::fs::File::try_lock()` in sorted canonical-path order (`site.lock` and `<db>.opendash.lock`) before `init_db` / startup recovery, holding locks in `Arc<CoordinatorInner>`.
   - `admit_mutation()` returns `MutationLease` or `503 Service Unavailable` with `Retry-After: 3` during maintenance.
   - `begin_maintenance(kind, deadline)` blocks new writers, drains active `MutationLease`s up to `<= 30s`, and returns an unforgeable `ExclusiveOpsContext` (or `DrainTimeout` reopening normal admission).
   - `OperationCancelSignal` provides cooperative cancellation + task join.
4. **Job Ledger Storage ([`storage/operations.rs`](../../cms/crates/opendash-server/src/storage/operations.rs), [`storage/mod.rs`](../../cms/crates/opendash-server/src/storage/mod.rs)):**
   - `create_job`, `get_job`, `list_jobs`, `transition_job_cas` (`412` on CAS version mismatch), `prune_old_receipts` (`MAX_RETAINED_OPERATION_RECEIPTS = 200`), `mark_interrupted_on_startup` (called in `main.rs`), and `bump_maintenance_generation`.
