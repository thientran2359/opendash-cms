## Tái hiện lỗi F06 và thay đổi

Tracked runner gốc (trước patch) đã **FAIL exit 1** trên Mac:
`Page.click: Timeout 30000ms exceeded`, chờ
`button:has-text("Builder")`. Giao diện thực tế dùng **Giao diện →
Visual Builder** (`#/builder`) và **Công cụ → Sao lưu & Phục hồi**
(`#/tools/backup`); trang Builder có `data-testid="builder-workspace"`.
Scratch navigation trong #297 không được thay thế tracked-runner evidence.

PR #344 chỉ sửa `cms/scripts/m8_browser_e2e.py`: selector semantic với
accessible name chính xác, readiness và giới hạn timeout, supervisor
watchdog/process group dọn đúng tiến trình sở hữu, durable phase/receipt,
kiểm `READY.json` và config Safe Mode trước activate, HTTP public
`noindex`, SQLite integrity, source DB checksum, UI reauth + Admin
activation, Builder re-edit + Save, public page và **restart recovered
site sau activation** để chứng minh `safe_mode=false` bền vững.
Không thay product security, schema, backend, Admin layout hay API.
