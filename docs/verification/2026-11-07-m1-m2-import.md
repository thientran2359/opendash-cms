# M1/M2 sau khi nhập vào OpenDash CMS

Ngày 07/11/2026 trên Windows, Rust 1.99.1, Node 22.16.0 và Python 3.13.4. Mốc đích là `0ec91ec`. Trước khi chép mã, fingerprint cây nguồn khớp [baseline M1/M2](2026-11-07-m1-m2-source-baseline.md). Phạm vi và cách hợp nhất theo [bản đối chiếu module](../plans/2026-11-07-m1-m2-module-map.md).

## Phần đã nhập

- Hai crate Rust, Auth/RBAC/CSRF, lưu trang và registry, renderer theme, plugin Wasmi với worker riêng và ABI v1. HTTP server mở SQLite qua `SitePaths`. Worker xử lý stdio trước nhánh khởi động HTTP.
- Admin React 18.3.1/Vite 6.0.7 dùng chung cho cả hai URL Admin/Builder. Tệp JS/CSS có hai đường dẫn tương thích. Health trả `status: ok`, `database: ready`, `scaffold: false` khi SQLite sẵn sàng.
- Build PowerShell chạy từ vị trí script, lần lượt build Admin, plugin mẫu và executable. Test phân phối thử lỗi thiếu lockfile và lỗi npm trong thư mục tạm. Quy tắc Git giữ LF của migration để ổn định checksum qua checkout trên Windows.

## Giới hạn

M1 cung cấp Builder một block. Dữ liệu block/theme và Wasm đã cài nằm trong SQLite. Kiểm thử trên trình duyệt là tự động, chưa có duyệt giao diện thủ công hoặc kiểm chứng binary Linux. CPT/Media, builder nhiều tầng và backup/restore là các mốc tiếp theo.
