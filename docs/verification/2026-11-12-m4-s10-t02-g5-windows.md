## Reproduction on Windows, from immutable release source

G5 runs `cms/scripts/m4_release_windows.py` copied unmodified from merged G4 PR #138 into the **detached source worktree**, to allow the script to assert `git rev-parse HEAD == --release-sha`. The G5 report is written in a separate docs worktree on `main`. Build and test commands executed:

```powershell
npm ci --prefix cms/admin --prefer-offline --no-audit
npm run typecheck --prefix cms/admin
npm run build --prefix cms/admin
cargo fmt --manifest-path cms/Cargo.toml --all -- --check
cargo build --manifest-path cms/Cargo.toml --locked --release
cargo test --manifest-path cms/Cargo.toml --workspace --locked --release
$env:PYTHONIOENCODING='utf-8'
python cms/scripts/m4_release_windows.py --binary cms/target/release/opendash.exe --m3-binary 'C:/Users/Thientran/Local Sites/opendash-workspace/opendash-cms-forge-m3-s30-t01/cms/target/release/opendash.exe' --browser 'C:/Program Files/Google/Chrome/Application/chrome.exe' --release-sha a176414bba5b7b85f408137ef0e0b964c2329843
```

Four additional foundation commands (from the same `cms/` source checkout) ran independently:

```powershell
python -X utf8 scripts/windows_auth_smoke.py --binary target/release/opendash.exe --baseline-db fixtures/baseline_0001.sqlite
python -X utf8 scripts/windows_plugin_smoke.py --binary target/release/opendash.exe
python -X utf8 scripts/windows_plugins_browser.py --binary target/release/opendash.exe --browser 'C:/Program Files/Google/Chrome/Application/chrome.exe'
python -X utf8 scripts/windows_kernel_smoke.py --binary target/release/opendash.exe
```

Raw binaries and temporary test fixtures are held locally and not checked into Git. This is an OS-specific verification, not a deployment. The old M3 browser `themes_browser.py` addresses obsolete M3 Builder controls; its equivalent M4 behavior is checked by the current Themes UI in this runner, `themes_smoke.py` and current Builder browser tests.
