## Changes Implemented

1. **Migration (`cms/migrations/0030_media_video.sql`)**:
   - Rebuilt `media_assets` without `PRAGMA foreign_keys = OFF` by backing up and restoring all referencing child tables (`builder_homepage_media`, `theme_option_media_refs` including M6 `owner_kind`/`owner_id`, `entry_seo`, `site_home_seo`, `seo_public_media_refs`).
   - Added `kind` (`'image' | 'video'`), nullable `thumb_width`/`thumb_height`, `duration_ms`, `video_codec`, `audio_codec`, and branched `CHECK` constraints preserving existing 8 MiB image limits while adding 100 MiB / 3840x2160 / 1..600000 ms `video/mp4` constraints.
2. **Bounded MP4 Inspector (`cms/crates/opendash-server/src/media_video.rs`)**:
   - Implemented `inspect_mp4` with checked-slice parsing: compatible `isom`/`mp42` `ftyp`, single `moov <= 2 MiB`, `>= 1` `mdat`, `<= 4096` boxes, `<= 8` depth, `<= 2` tracks, `<= 100,000` samples, `5s` timeout checks, non-overlapping sample ranges inside `mdat`, H.264 `avc1`/`avcC` SPS+PPS dimension verification matching `tkhd`/`avc1`, and optional `mp4a` AAC-LC `esds` validation.
3. **Streaming Upload & Staging (`cms/crates/opendash-server/src/media.rs`, `src/routes/media.rs`, `src/main.rs`, `src/app.rs`, `src/error.rs`)**:
   - Added `POST /api/admin/media/video` (`DefaultBodyLimit::max(100 MiB)`, `429` concurrency cap of 2 ingests, `415` for non-`video/mp4`, streaming SHA-256 + staging file with RAII drop cleanup and startup `.staging` cleanup, durable atomic rename before metadata commit).
   - Added `?kind=image|video` filtering on `GET /api/admin/media` and `404` on `GET /api/admin/media/{id}/thumbnail` for videos.
4. **Typed Image-Ref Enforcement (`cms/crates/opendash-server/src/storage/media.rs`, `builder.rs`, `seo.rs`, `settings.rs`)**:
   - Enforced `kind = 'image'` in entry `image`/`gallery`, Builder `core/image`, SEO `og_image_id`, and theme/plugin `image_ref` validators.
5. **Admin API & Preflight (`cms/admin/src/api/media.ts`, `cms/admin/src/features/media/library/fileValidation.ts`, `MediaLibraryPage.tsx`, `MediaPicker.tsx`)**:
   - Updated `MediaAsset` type for `kind`, nullable thumbnail dimensions, and video metadata; added `uploadVideo` and `validateVideoUpload`.
