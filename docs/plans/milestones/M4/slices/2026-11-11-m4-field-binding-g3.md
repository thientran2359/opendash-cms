- **Milestone/slice:** M4 / M4-S05. **Track:** Full-Track. **Owner:** Harbor (CoS macOS) proposed under owner-direct implementation instruction.
- **Goal:** On homepage, configured core Heading/Text/Image/Button element renders selected built-in title or declared custom Post/Page/CPT field without arbitrary query or draft exposure. Missing or incompatible sources render no node with diagnostic; stored layout and ID survive restart.
- **Implementation:** add optional typed binding to existing core element props with `type_key/entry_slug/source/target`; query exact entries in server storage with published-only public guard and authenticated Preview; escape and validate according to ADR-0009 matrix; preserve P02 singleton/ETag/preview/media ACL and legacy fallback; no migration.
