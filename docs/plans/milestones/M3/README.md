**M3 phải có:** setup Admin + login/logout; `post` và `page` core-owned tự có; Posts/Pages CRUD + editor form, ảnh đại diện và draft/published tối thiểu, public/preview an toàn; trang Media Library, Users (Admin/Editor), Dashboard, General Settings (site title/tagline/timezone), Appearance→Themes (ZIP/list/activate cơ bản), Plugins (ZIP/list/enable/disable), Builder cũ còn hoạt động. Admin có sidebar/topbar/responsive/routing và phân quyền thực. Xem [M3 TASK_PLAN](TASK_PLAN.md) để biết dependency/gate/acceptance cho từng candidate. Tính năng nâng cao như taxonomy, plugin CPT bridge, media video/delete/reconcile, Builder AST, Theme Options/SEO/backup được phân bổ đến M4–M8; **không loại khỏi V1**. Nhóm #15 chỉ là input kỹ thuật lịch sử, không phải backlog thay cho phạm vi chủ dự án chốt.

**M3 G5/closure (đề xuất, chưa có PASS):** clean install/upgrade → bootstrap/login → create/edit `post`/`page` → upload/chọn ảnh → **Lưu draft chỉ vào DB, preview cần auth, Xuất bản mới hiện public, Lưu published cập nhật public** → quản lý Users/Settings → ZIP theme install/list/activate → plugin install/enable/disable → logout/login/restart giữ dữ liệu; **Builder Lưu vẫn công khai trên `/`**. Kiểm RBAC/CSRF/Origin/401/412/escaping/XSS/media ACL/compatibility homepage. Evidence ghi SHA/OS, macOS E2E và Windows smoke/parity độc lập; Linux release cuối V1 thuộc M8. Không đóng M3 khi acceptance mới chưa G5.
