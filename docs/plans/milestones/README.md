# Kế hoạch từng milestone

Mỗi milestone có một kế hoạch ghi phạm vi, module/capability liên quan, dependency, slice, tiêu chí nghiệm thu, phần ngoài phạm vi và các tài liệu contract/ADR/verification. **Trạng thái hiện hành của milestone/slice chỉ cập nhật trong [Roadmap V1](../ROADMAP_V1.md)**, không tạo bảng trạng thái bản sao tại mục lục này.

| Mốc | Kế hoạch hoặc tài liệu đầu vào |
| --- | --- |
| M2.5 — Core Foundation | [M2.5-core-foundation.md](M2.5-core-foundation.md); [bằng chứng 07/11/2026](../../verification/2026-11-07-m2-5-core-kernel.md) |
| M3 — Content & Media | [Roadmap V1](../ROADMAP_V1.md) và [Module Catalog](../MODULE_CATALOG_V1.md); milestone plan chi tiết chỉ tạo sau G1/G2 |

Khi mở milestone, dùng [Planning Workflow](../PLANNING_WORKFLOW.md), [Module Brief](../templates/MODULE_BRIEF.md) và [Slice Task](../templates/SLICE_TASK.md). Hồ sơ chuyển đổi lịch sử lưu tại [archive](../../archive/README.md).
