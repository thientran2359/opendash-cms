# Tài liệu Lưu trữ (`docs/archive/`)

Các tài liệu kế hoạch G0–G5 cũ (`archive/plans/`), luồng thảo luận liên-agent cũ (`archive/discussions/`) và nhật ký tách cấu trúc M1/M2 (`archive/migrations/`) đã được dọn khỏi cây thư mục làm việc để giảm ngữ cảnh thừa cho agent.

Lịch sử đầy đủ vẫn được lưu giữ trong Git history (các commit trước khi chuẩn hóa quy trình EGM). Các đặc tả thiết kế và quy chuẩn hiện hành nằm tại:

- [`docs/designs/SITEMAP.md`](../designs/SITEMAP.md) — Danh mục đặc tả EGM
- [`docs/contracts/CORE_FOUNDATION.md`](../contracts/CORE_FOUNDATION.md) — Hợp đồng lõi hệ thống
- [`docs/decisions/ADR-0010-agent-project-and-merge-authority.md`](../decisions/ADR-0010-agent-project-and-merge-authority.md) — Phân quyền & thẩm quyền merge
