# Thread lịch sử

Các thread cũ ghi lại lượt nghiên cứu/phản biện tại thời điểm M3 chưa triển
khai. Không tiếp tục ghi lượt mới vào đây hoặc suy rằng mọi phương án G2
`PROPOSED` đã được phê duyệt hồi tố khi mã nguồn M3.1–M3.6 được merge.

Để biết phần đã làm, xem [bảng trạng thái M3](../../plans/M3_STATUS_2026-11-09.md).
Để mở thảo luận mới, dùng [`.agents/discussions/`](../../../.agents/discussions/)
và quy trình GitHub trong [tài liệu vận hành](../../../.agents/GITHUB_WORKFLOW.md).
