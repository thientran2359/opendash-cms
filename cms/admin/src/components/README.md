# Shared UI Components (`cms/admin/src/components/`)

Các thành phần giao diện dùng chung giữa `shell/`, `builder/` và `features/`:

- `FormPrimitives.tsx`: `TextInput`, `FormGroup`, `TextField`, `SelectField`, `ZipUploadField` — dùng chung để thống nhất kiểm soát nhập liệu, nhãn truy cập và hiển thị lỗi trên toàn bộ màn hình Admin.
