# Kiểm thử dữ liệu

Thư mục dành cho fixture database và test package thực tế. File `baseline_0001.sqlite` chỉ được thêm khi nhập bản fixture đã kiểm chứng từ repository nguồn; chưa tạo file SQLite giả.

Database local `../database/opendash.sqlite` (tính từ `cms/`) hoặc `database/opendash.sqlite` (tính từ gốc website) được tạo khi chạy server và được loại trừ bởi `.gitignore`.
