# Sample Theme — draft

`templates/hero.html` minh họa cú pháp MiniJinja. Các biến `title` và `description` là dữ liệu demo cần được escape theo ngữ cảnh khi render.

Chưa có manifest/block schema, asset packaging hay quy trình cài theme ZIP. Bổ sung các thành phần đó sau khi contract theme được triển khai, tránh tạo gói giả có vẻ cài được.
